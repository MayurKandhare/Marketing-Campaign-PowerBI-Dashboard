# 📊 Marketing Campaign Power BI Dashboard

## 📌 Project Overview

This project is an interactive **Marketing Campaign Analytics Dashboard** built using **Microsoft Power BI**.

The dashboard helps analyze marketing campaign performance, customer engagement, conversions, and key business metrics to identify trends and support data-driven marketing decisions.

## 🎯 Objectives

* Analyze overall marketing campaign performance
* Track key marketing KPIs
* Understand customer engagement and conversion patterns
* Compare campaign performance
* Identify high-performing and underperforming campaigns
* Provide actionable insights through interactive visualizations

## 🛠️ Tools & Technologies

* **Power BI**
* **Power Query**
* **DAX**
* **Data Cleaning & Transformation**
* **Data Visualization**
* **Interactive Dashboards**

## 📈 Dashboard Highlights

* Marketing KPI overview
* Campaign performance analysis
* Customer engagement analysis
* Conversion analysis
* Campaign comparisons
* Interactive filters and slicers
* Data-driven visual insights
